# Intelligent Investor Masterclass

An interactive, browser-based learning experience that presents the core ideas in Benjamin Graham's *The Intelligent Investor* as a concise 16-part lesson.

## Live demo

[Open the Intelligent Investor Masterclass](https://chris217024.github.io/intelligent-investor-masterclass/)

## Highlights

- Sixteen sequenced learning sections
- Responsive presentation-style interface
- On-screen, keyboard and progress-dot navigation
- Clear explanations of value investing, investor psychology, intrinsic value and margin of safety
- Self-contained static implementation with no build step

## Built with

- Semantic HTML
- Custom CSS
- Vanilla JavaScript
- Google Fonts
- GitHub Pages

## Project structure

```text
.
├── index.html   # Complete interactive lesson
├── README.md    # Project documentation
└── .nojekyll    # Static GitHub Pages configuration
```

## Run locally

Download the repository and open `index.html` in a modern browser. No dependencies or installation are required.
