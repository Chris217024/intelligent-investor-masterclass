# Intelligent Investor Masterclass

An interactive, browser-based learning experience that distils the core ideas in Benjamin Graham's *The Intelligent Investor* into a concise 16-part lesson.

## What it demonstrates

- Learning experience design and content sequencing
- Responsive, presentation-style web design
- Keyboard and on-screen navigation
- Clear visual hierarchy for complex educational material
- A self-contained HTML implementation with no build step

## View the project

Open `index.html` in a modern browser, or use the repository's GitHub Pages deployment if enabled.

## Purpose

This project is an independent educational interpretation created as a portfolio demonstration. It is not affiliated with Benjamin Graham's estate, the book's publisher, or any financial institution.

## Important notice

The material is for education only and is not financial advice. Examples and simplified valuation concepts should not be used as a substitute for professional advice or independent research.
